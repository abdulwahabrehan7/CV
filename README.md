# FORME — CV Maker — Resume Builder Web App

An interactive web application designed to help users create, format, and structure professional CVs and resumes.

**Live Demo:** [abdulwahabrehan7.github.io/CV/](https://abdulwahabrehan7.github.io/CV/)

## Overview
- Streamlines the process of building clean, structured, and professional resumes.
- Features intuitive input handling and layout rendering for efficient document generation.

## Tech Stack
- HTML5, CSS3, JavaScript
